# picoCTF Writeups

![Image](cylab.svg)

Welcome to my cylabacademy writeups collection. This repository contains step-by-step solutions for cylabacademy practice challenges, with a focus on clarity and learning.

- Author: [AliMoussa](https://learn.cylabacademy.org/users/AliMoussa)
- Platform: [cylabacademy](cylabacademy.org)
- Coverage: 225+ challenge solutions

## What you will find

This repository is primarily a personal reference, but it is also shared for others who want to learn offensive security techniques and CTF problem solving.

Each writeup is designed to be:

- clear and well structured
- focused on methodology rather than just the final answer
- easy to follow for both beginners and experienced users

## Spoiler policy

The writeups include detailed walkthroughs, but flags are not shown in plain text.

- Flags are replaced with placeholders like `picoCTF{<REDACTED>}`
- Solutions still explain how to reach the final answer
- Walkthroughs may provide direct answers only when they are not flag-like
