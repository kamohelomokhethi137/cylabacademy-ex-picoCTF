## 🏷️ Categories by Type

Below is a quick map of categories and representative challenges (lists reference actual PDF files in the `Forensics` folders).

### 🖥️ Disk Forensics
Disk image analysis, recovery, and low-level sectors.


### 🔐 Steganography
Hidden data in images, audio, and polyglots.

### 🌐 Network Analysis
PCAP captures, protocol analysis, and WiFi investigation.

### 💾 Metadata & Files
EXIF, signatures, polymorphic files, integrity.

### 📊 Memory & Processes
RAM analysis and system artifacts.

### 📋 Logs & Timeline
Event logs and timeline reconstruction.

### 🔒 Encryption & Protection
BitLocker and other encrypted containers.

### 🔢 Format & Encoding
Endianness, MSB/LSB and byte-order issues.

### 📚 Other Sources
Git repository forensics, torrent analysis, external datasets.
